База ников

  1. Перетащите ссылку Собрать ники BongaCams на панель закладок браузера (один раз).
  2. Откройте bongacams.com и нажмите эту закладку. Она пройдёт по каталогу (/tools/listing_v3.php — ник и номер сервера) и по /sitemap.xml из robots.txt (только имена), а результат положит в буфер обмена.
  3. Вернитесь сюда и нажмите «Обновить аккаунты» — список подхватится из буфера сам. Если браузер не даёт читать буфер, вставьте JSON в поле ниже вручную.

Списки складываются: повторный сбор на других вкладках каталога (парни, пары) только дополнит базу.
