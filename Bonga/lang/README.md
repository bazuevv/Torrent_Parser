# Словари интерфейса

Один файл — один язык: `<код>.json`, где код это две буквы (`en`, `de`) либо
две с областью (`pt-br`). Сервер отдаёт список файлов по `GET /api/langs`, сам
словарь — по `GET /api/lang/<код>`.

Добавить язык значит положить сюда файл. Ни страницу, ни сервер править не
нужно: список в настройках наполняется тем, что реально лежит в этой папке.

Русский лежит здесь же, наравне с остальными: папка должна показывать
настоящую картину, а не половину её. Мигания ключами при загрузке это не даёт —
русский текст написан прямо в разметке, и словарь лишь подменяет его при другом
языке. Пока словарь не пришёл, страница выглядит по-русски, что для запасного
варианта ровно то, что нужно.

## Формат

    {
      "панель.видео": "Video",
      "стена.ушли": "Left the air: {кто}."
    }

Ключ именуется по месту в интерфейсе: `панель.*`, `настройки.*`, `стена.*`.
Подстановки — по именам в фигурных скобках, а не по номерам: при переводе
порядок слов меняется, и номера начинают путаться местами.

Переводить весь файл сразу не обязательно. Недостающие ключи берутся из
русского: перевод может отставать от страницы, и смешанный язык лучше, чем
дыры в интерфейсе.

## Сверка

    python3 lang/check.py          # все словари
    python3 lang/check.py en       # только один

Показывает, сколько переведено, каких ключей не хватает, какие остались от
удалённых кусков интерфейса и где разошлись подстановки. Последнее важнее
всего: если в русском «{сколько} с», а в переводе «{count} s», человек увидит
буквально `{count}`, и ошибку заметят не сразу.

Неполный перевод ошибкой не считается — недостающее берётся из русского.
Ошибка это лишние ключи и разъехавшиеся подстановки.

## Что лежит сейчас

`en.json` — образец, а не готовый перевод: в нём 25 ключей из 708. Остальное
интерфейс возьмёт из русского, так что выбор English даст смесь языков. Это
намеренно: файл показывает формат и доказывает, что механизм работает.

Полный перевод — отдельная работа: 708 ключей, около 23 тысяч символов, самое
объёмное в них — пояснения под значками «i» в настройках.
