# «Отклик» — прототипы пофрагментной оценки

Два интерактивных прототипа одной идеи: вместо одного лайка на весь трек или
ролик зритель ставит оценку **каждому фрагменту отдельно**, тремя уровнями
«Нравится». Отсутствие оценки означает ноль — отдельной кнопки дизлайка нет.

| Файл | Пример | Опубликованная версия |
|---|---|---|
| [otklik-music.html](otklik-music.html) | песня, разбитая на секции (интро, куплеты, припевы, бридж, аутро) | https://claude.ai/code/artifact/fe936487-cc05-4913-8792-b56dda1bc4db |
| [otklik-video.html](otklik-video.html) | видео, разбитое на главы | https://claude.ai/code/artifact/8113cd8b-3dc4-44ef-a589-cb723335697a |
| [otklik-youtube.html](otklik-youtube.html) | живой тест на настоящем ролике YouTube | требует локального сервера, см. ниже |

## Что показывают прототипы

Три вкладки в каждом файле:

- **Зритель / слушатель** — плеер, полоса фрагментов, оценка текущего фрагмента
  уровнями 1–3 (повторное нажатие снимает оценку), режим раздельной оценки двух
  слоёв: «музыка и слова» для песни, «видео и звук» для ролика. Ниже график
  своей кривой с опциональным наложением средней по всем оценившим.
- **Автор** — распределение оценок по каждому фрагменту: сколько человек
  слушали/смотрели без оценки и сколько поставили каждый уровень, плюс средние
  по обоим слоям.
- **Профили вкуса** — кривая другого пользователя поверх своей и процент
  совпадения. Видимость профиля: «для друзей» или «публично».

Все данные демонстрационные, песня, ролик и исполнители вымышленные.

## Живой тест на ролике YouTube

`otklik-youtube.html` подключает систему оценок к настоящему ролику
(«ГОНИМ БЕНЗИН ИЗ ТРАВЫ», канал «Гараж 54», 35:40). Собственных глав у ролика
нет, поэтому он режется равными фрагментами — 6, 12 или 24 на выбор; для каждой
дробности хранится свой набор оценок, в `localStorage` браузера.

Плеер управляется через `postMessage` напрямую (`enablejsapi=1`), без загрузки
внешнего скрипта YouTube API — так страница остаётся самодостаточной.

**Открывать только через веб-сервер.** С `file://` YouTube отказывается
встраивать плеер (ошибка 153), потому что origin получается `null`:

```sh
cd otklik && python3 -m http.server 8791
# затем http://localhost:8791/otklik-youtube.html
```

## Как открыть

Первые два файла самодостаточные: шрифт вшит как data-URI, внешних запросов нет.
Достаточно открыть любой из них в браузере.

Разметка намеренно начинается сразу с `<title>` и `<style>`, без `<!doctype>` и
`<html>` — это исходники для публикации в виде Artifact, где страница
оборачивается в скелет автоматически. Браузер открывает их и без обёртки.

## Что обсуждалось, но в прототип не заложено

- оценка голосом (для случаев, когда руки заняты — за рулём, на тренировке);
- произвольные отрезки вместо готовых секций и глав;
- построчный слой для текста песни (в духе аннотаций Genius).
