# Правила работы Codex в этом репозитории

Перед началом работы обязательно прочитать и соблюдать корневой `CLAUDE.md`.
Его правила контрольных точек, TodoWrite, подтверждений пользователя и
безопасности Git распространяются и на Codex.

## Контрольные коммиты

- Каждая завершённая фаза верхнего уровня должна заканчиваться отдельным
  коммитом до перехода к следующей фазе.
- Добавлять в индекс только конкретные файлы текущей фазы. Не использовать
  `git add .` и `git add -A`.
- Сообщение коммита оформлять так:

      Этап <N>, фаза <M.K>: <краткое описание>

- После коммита показать `git diff --stat HEAD~1`, кратко назвать следующую
  фазу и спросить «Продолжать?».
- Ответы `да`, `ок` и `продолжай` разрешают только следующую фазу. Ответ `даа`
  разрешает выполнить оставшиеся фазы текущего плана без промежуточных
  вопросов, но не отменяет отдельные коммиты и ведение плана.
- Одновременно в плане может быть только одна фаза со статусом `in_progress`.
  Фазу отмечать завершённой только после её коммита.

Если это краткое изложение расходится с `CLAUDE.md`, приоритет имеет более
подробное правило из `CLAUDE.md`.
